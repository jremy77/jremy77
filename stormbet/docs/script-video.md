# Script de tournage — vidéo avec présentateur·rice réel·le

Les vidéos livrées utilisent « Nova », une présentatrice animée. Pour tourner avec une vraie
personne (ou un avatar IA type HeyGen / Synthesia), voici le découpage. L'écran du site est
incrusté à droite ; la personne est filmée sur fond vert, cadrée taille, à gauche.

**Ton de voix** : celui de quelqu'un qui contemple un paysage magnifique. Lent (≈ 120 mots/min),
grave et chaleureux, sourire dans la voix, souffle audible entre les phrases, jamais « vendeur ».
Micro proche, pièce traitée ; en post-prod : léger grave (+3 dB à 180 Hz), aigus adoucis, courte réverbération.
